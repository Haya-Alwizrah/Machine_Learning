Project Details

This project analyzes skills using TF-IDF technology to convert text into numerical vectors. It then utilizes the K-Nearest Neighbors (KNN) algorithm to measure similarity (via Cosine Similarity) between user skills and required job skills.

Multiple models were tested, and the KNN model proved its accuracy and superiority in providing recommendations compared to clustering models like K-Means.
